# Cover composition studies 01

Four raster concepts generated with the built-in image_gen tool at the organizer's request. These explore composition, title scale, and a much smaller S11. Existing SVG revisions remain unchanged.

- [A](a-diagonal.png): ascending diagonal title.
- [B](b-horizontal.png): straight horizontal title with a small season tag above the O.
- [C](c-staggered.png): staggered letter sizes and baselines.
- [D](d-stacked.png): compact OC / LR two-line title.

Exact prompts and input paths are retained in [prompts.json](prompts.json). Inputs are the R05 angular wordmark, the existing AI-assisted Liru adaptation, and the existing cleaned sunset scene. Liru's underlying character is by JerrYamada, CC BY 4.0; see [the design provenance](../README.md). Generated images are concept explorations, not approved replacement mascot sheets or exact vector paths.

This is a local review page, not a homepage integration or deployment. No tournament data, dates, sponsors, or publication claims were added. Open each image to review at full size.
