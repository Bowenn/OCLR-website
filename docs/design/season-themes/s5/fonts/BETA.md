# S5 beta lettering

The decorative **β** (Greek small letter beta, U+03B2) uses **EB Garamond Italic**, weight 400, by Georg Duffner and Octavio Pardo. The glyph was converted to SVG outlines for the S5 prismatic background; the application does not load or install the font.

- [Official font metadata](https://github.com/google/fonts/blob/main/ofl/ebgaramond/METADATA.pb)
- [Source font](https://github.com/google/fonts/blob/main/ofl/ebgaramond/EBGaramond-Italic%5Bwght%5D.ttf)
- [SIL Open Font License 1.1 and copyright notice](OFL-EBGaramond.txt)
- Source TTF SHA-256: `bba2c4499c93c9612b90b9825d32b07da52fce2fe57562a1eb6b833553f93c4e`
- Conversion: CoreText, font size 1000, U+03B2 → glyph 1839; original bounds `(-54.133333, -285, 504.133333, 990)`.
- Normalize the outline to 198 SVG units high at `(1268, 20)` in the 1600×240 background. Keep the natural italic proportions, thick/thin strokes and descender. Gradient fill and fine edge shading embed the lettering in the faceted surface.

The two [shipped SVG textures](../../../../../public/themes/prism-overture/) contain the final outline and local gradients. The full font is not bundled. MainSheet interface typography and the original OCLR β key visual remain unchanged.
