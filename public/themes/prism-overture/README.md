# S5 Prism Overture assets

The static SVG textures contain 110 original geometric facets and a decorative Greek β (U+03B2) outlined from EB Garamond Italic 400. The application makes no runtime font request.

See the [lettering source and conversion record](../../../docs/design/season-themes/s5/fonts/BETA.md) and the bundled [SIL OFL 1.1 licence](OFL-EBGaramond.txt). The complete original OCLR β artwork remains at `/archive/s5/key-visual.png`.
