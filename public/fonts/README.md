# Quicksand

The Latin variable subset is adapted from `origin/style/cute-pastel-ui` (9d95608).
Source: https://github.com/andrew-paglinawan/QuicksandFamily

Licensed under SIL Open Font License 1.1; see `Quicksand-OFL.txt`.
Only the selected cute-pastel appearance uses this local font. CJK text retains
the site's locale-aware system fallbacks. No runtime font service is requested.

# Bangers

`bangers-latin-400.woff2` is the unmodified Latin subset from the
`@fontsource/bangers` 5.3.0 package (Google Fonts v25, Bangers 2.100).
Source: https://github.com/googlefonts/bangers

Copyright 2010 The Bangers Project Authors. Licensed under SIL Open Font
License 1.1; see `Bangers-OFL.txt`. Only the selected manga-halftone appearance
uses it, for English display titles, eyebrows and map slot labels. Its
`unicode-range` is limited to Latin, so Chinese text always uses the system sans
at 700. The font has a single 400 weight; weight synthesis is disabled. No
runtime font service is requested.

# Barlow Condensed

ExtraBold Italic (800) Latin subset from
`@fontsource/barlow-condensed` 5.3.0, a packaging of the Google Fonts release.
Source: https://github.com/jpt/barlow

Licensed under SIL Open Font License 1.1; see `BarlowCondensed-OFL.txt`.
Only the selected esports-broadcast appearance uses this local font, for English
display titles and short Latin labels. Its `unicode-range` covers Latin only, so
CJK text keeps the upright locale-aware system fonts. No runtime font service is
requested.
