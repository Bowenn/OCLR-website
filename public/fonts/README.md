# Quicksand

The Latin variable subset is adapted from `origin/style/cute-pastel-ui` (9d95608).
Source: https://github.com/andrew-paglinawan/QuicksandFamily

Licensed under SIL Open Font License 1.1; see `Quicksand-OFL.txt`.
Only the selected cute-pastel appearance uses this local font. CJK text retains
the site's locale-aware system fallbacks. No runtime font service is requested.

# Bangers

`bangers-latin-400.woff2` is the unmodified Latin subset from the
`@fontsource/bangers` 5.3.0 package (Google Fonts v25, Bangers 2.100).
Source: https://github.com/googlefonts/bangers

Copyright 2010 The Bangers Project Authors. Licensed under SIL Open Font
License 1.1; see `Bangers-OFL.txt`. Only the selected manga-halftone appearance
uses it, for English display titles, eyebrows and map slot labels. Its
`unicode-range` is limited to Latin, so Chinese text always uses the system sans
at 700. The font has a single 400 weight; weight synthesis is disabled. No
runtime font service is requested.

# Barlow Condensed

ExtraBold Italic (800) Latin subset from
`@fontsource/barlow-condensed` 5.3.0, a packaging of the Google Fonts release.
Source: https://github.com/jpt/barlow

Licensed under SIL Open Font License 1.1; see `BarlowCondensed-OFL.txt`.
Only the selected esports-broadcast appearance uses this local font, for English
display titles and short Latin labels. Its `unicode-range` covers Latin only, so
CJK text keeps the upright locale-aware system fonts. No runtime font service is
requested.

# Press Start 2P

`PressStart2P-Regular.ttf` is the unmodified font file from
https://github.com/google/fonts/tree/main/ofl/pressstart2p (designer CodeMan38;
SHA-256 `034c77f1f05ec89421e4a63f0e3a4ca1ecf852cc6d2bf611f126f275728e017d`).
It is licensed under SIL Open Font License 1.1 with Reserved Font Name
"Press Start 2P"; see `PressStart2P-OFL.txt`. Because a subset or re-encoded file
would be a Modified Version that may not keep that name, the original file is
shipped as-is (118 KB) and the CSS `unicode-range` limits it to Latin text.
Only the selected retro-arcade appearance uses it, for large Latin headings. CJK text keeps
the system fallbacks. No runtime font service is requested.

# Fusion Pixel Font (12px proportional)

`fusion-pixel/` holds the unmodified zh_hans, zh_hant and latin `.otf.woff2`
files from the TakWolf/fusion-pixel-font release `2026.10.25`
(https://github.com/TakWolf/fusion-pixel-font, asset
`fusion-pixel-font-12px-proportional-otf.woff2-v2026.10.25.zip`, SHA-256
`0501b4f770887eef5fc5ac94401b3b7bb38253ffed3a549e2cb0be89a0a03fe3`).

Licensed under SIL Open Font License 1.1 with no Reserved Font Name; see
`fusion-pixel/OFL.txt`. The font includes glyphs from Ark Pixel Font, Cubic 11
and Galmuri, whose OFL licences are in `fusion-pixel/LICENSES/`. Only the selected
retro-arcade appearance uses it, for all of its text apart from Latin headings.
Each page loads only the file for its locale (about 0.7 MB). No runtime font
service is requested.
